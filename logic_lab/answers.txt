Task 8: Connect Prolog to Logical Reasoning
Explanation: The query `?- reduce_speed.` succeeds because `reduce_speed` is implied by `slippery`, which is implied by `wet_road`, which is established as a fact[cite: 14].
Logical reasoning sequence:
Fact (wet_road) => Rule (wet_road -> slippery) => Rule (slippery -> reduce_speed) => Conclusion (reduce_speed)[cite: 14].

7.2 Reflection
1. A Prolog fact is an unconditionally true statement, while a Prolog rule denotes a conditional implication[cite: 11, 14].
2. A Prolog query asks the system to use its inference mechanism to determine if a statement logically follows from the facts and rules in the knowledge base[cite: 14].
3. Prolog provides an independent, formal system to verify that the actions generated by a Python search program are logically consistent with the environment's rules[cite: 13, 14].
4. An independent verifier guarantees the output logically strictly follows the rules, confirming the LLM output is valid and not a generated hallucination[cite: 10, 13, 14].
